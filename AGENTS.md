# Asobiba — вход для агентов

**Asobiba** (遊び場, «игровая площадка») — сайт мини-игр владельца и его друзей.
Новые игры добавляет разработчик, а игроки и их ИИ-агенты настраивают существующие
через гибкие настройки: правила, режимы, раунды, таймеры, визуал. Агент собирает
конфиг через MCP из возможностей SDK и создаёт лобби. Правки вносит только владелец,
поэтому процесс лёгкий. Видение и принципы — в [`.ai/vision.md`](.ai/vision.md).

Этот файл одинаково читают Claude Code (через `CLAUDE.md`), Codex и Cursor.

## Стек и команды

TypeScript-монорепо на npm workspaces · Node 22 · Zod 4 · Fastify 5 + WebSocket ·
Prisma 7 + SQLite · Vite + React 19 · MCP (Streamable HTTP) · Vitest.

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер на :8787 и сайт на :5173 (Vite проксирует API). Сначала проверь порты, см. [dev-env](.ai/map/dev-env.md) |
| `npm start` | продакшен: один процесс на :8787 отдаёт собранный сайт, API, WebSocket и MCP |
| `npm run invite` | ссылка-приглашение на регистрацию (`-- --admin` для админа) |
| `npm test` → `npm run build` → `npx tsc --noEmit` | обязательная тройка проверок, именно в этом порядке |

Первый запуск и переменные окружения описаны в [`README.md`](README.md).

## Как ведём задачи

Каждая задача идёт по стадиям скилла [`feature`](.claude/skills/feature/SKILL.md):
бриф → продукт (если нужен) → техника → план → реализация и QG → проверка
владельцем → вливание через PR. У задачи своя папка `.ai/features/NN-slug/`,
её статус записан во frontmatter `README.md`. Гейты — явные ответы владельца
(«продукт ок», «техника ок», «принято»). После плана гейта нет.
**Без «принято» не вливать.** Исключение — автономный режим. Если владелец явно написал,
что задачу можно вести автономно, гейты пропускаются. Агент сам принимает и записывает
решения, проходит QG и ревью, затем вливает PR в `main`. Разрешение действует на одну
задачу. Подробности — в разделе скилла «Автономный режим».

## Скиллы

Скиллы лежат в `.claude/skills/`. `.agents/skills` — симлинк на эту папку для Codex,
Cursor читает обе. Если владелец назвал скилл или запрос совпал с его триггером,
прочти `SKILL.md` целиком и выполни. В Codex скилл вызывается как `$имя`, в Claude Code и Cursor — `/имя`.

| Скилл | Для чего | Когда |
|---|---|---|
| [`feature`](.claude/skills/feature/SKILL.md) | стадии задачи | новый бриф, «статус», «продукт ок», «принято» |
| [`verify`](.claude/skills/verify/SKILL.md) | QG и живая проверка | стадия QG, перед PR, «проверь» |

Плагин superpowers, если он есть, можно использовать внутри стадий. Но его
артефакты кладутся в папку задачи, а не в `docs/superpowers/`.

## Правила

- Доки и общение — по-русски. Код, идентификаторы и коммиты — по-английски, в conventional-стиле: `feat(sdk): …`.
- ИИ-материалы хранятся только в `.ai/` и здесь. Новый тип материалов — новая подпапка и строка в [`.ai/README.md`](.ai/README.md).
- Поменял поведение зоны — поправь её карточку в той же ветке. Папки влитых задач — архив, их не переписываем.
- Готовность не объявляется по типам и юнитам. Обязательно: тройка после последних
  правок, плюс проверка на живой поверхности по затронутым зонам (сайт в браузере,
  партия по WebSocket, настоящий MCP, превью картинкой). Как именно — в скилле `verify`.
  Для правок только в доках тройку не гоняют, достаточно проверить ссылки.
- Репозиторий публичный. `.env` и `storage/` в `.gitignore`. Пароли и токены не печатать
  и не коммитить. Проверочные аккаунты и данные держать в `storage/`.
- Партия идёт на сцене во весь экран: как только игра началась, лобби скрывается за кнопкой «Лобби»,
  а доска занимает всё окно. Поэтому каждая игра обязана поддержать `BoardProps.stage` (доска
  растягивается на 100 % ширины и высоты сцены, без своих внешних отступов и прокрутки страницы)
  и полноэкранный режим через `BoardProps.fullscreen`. Своя кнопка полноэкранного режима, если она есть,
  вызывает `fullscreen.toggle()`. Подробности — в карточках [games](.ai/map/games.md) и [web](.ai/map/web.md).
- Конфиг игры — данные. SDK не исполняет произвольный код из конфига. Новая возможность
  добавляется расширением версионированной схемы игры, движка и рендерера.
- Агент собирает игры и лобби, но не ходит за людей. Сервис заново проверяет права и владение
  на каждый вызов MCP.
