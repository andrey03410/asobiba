# .ai — знания проекта

Вход для агента — [`AGENTS.md`](../AGENTS.md) в корне. Здесь то, на что он ссылается.

| Папка / файл | Что там | Живое или архив |
|---|---|---|
| [`vision.md`](vision.md) | Продуктовое видение и принципы | живое — меняется вместе с видением владельца |
| [`map/`](map/) | Карточки зон кода: где лежит, как устроено, грабли, как проверить | живое — правится вместе с кодом |
| [`features/`](features/) | Задачи: папка на задачу, файл на стадию | живое, пока задача не влита, потом архив |
| [`history.md`](history.md) | Строка на каждую влитую задачу со ссылками | дописывается при вливании |

Правила:
- Карточка `map/` описывает код **сейчас**. Поменял поведение зоны — поправь её карточку в той же ветке.
- Папки влитых задач — архив, их не переписываем: если решение устарело, актуальное пишется в карточку.
- Новый тип материалов — новая подпапка и строка в этой таблице.
