# План реализации ИИ в живой партии

> Выполнять по задачам с TDD, живой проверкой `verify` и независимым ревью всей ветки.

**Цель.** Тот же активный чат ведёт Quizor или наблюдает и комментирует партию другой игры.

**Подход.** SDK хранит паузу в журнале партии. Сервер владеет ролями, временем жизни подключения и
публичными событиями. Чат читает события и отправляет решения через MCP, а браузер показывает состояние
и действия хозяина. [Продукт](product.md), [техника](tech.md)

## Условия

- Node 22 и существующие npm workspaces. Документация задачи в `.ai/features/11-ai-game-roles/`.
- Оригинал конфига и проекция ведущего выдаются только в пределах конкретного полномочия.
- Проверить повторное подключение, действия с устаревшим событием, повторную доставку, рестарт
  и сохранение игрового времени. Существующие журналы и лобби читаются после миграции.

## Задачи

- [x] **1. Общая пауза SDK.** `packages/sdk/src/match.ts`, `match.test.ts`. Сначала красный тест
  паузы таймера, восстановления журнала и запрета хода. Реализовать `Match.setPaused(reason, at)`,
  `MatchView.pause`, `clockShiftMs`. Точечно прогнать SDK-тесты. Коммит `feat(sdk): pause matches`.
- [x] **2. Ведущий Quizor.** `games/quizor/src/game.ts` и тесты движка. Сначала проверить ожидающую
  оценку и переключение на алгоритм с живыми ответами. Добавить задание ведущего в его представление,
  определение совместимости и журналируемое управление алгоритмом. Коммит `feat(quizor): support live AI presenters`.
- [x] **3. Контракт и сервер.** `packages/api`, `packages/sdk/src/game.ts`, каталог игр, `apps/server/src/lobbies`,
  `routes.ts`, `mcp`, Prisma. Сначала тесты границ доступа, истечения ключа, смены ведущего и ожидания.
  Добавить роли и сжатые публичные события, хранение настроек, ключ подключения, команды хозяина,
  `agent_attach`, `agent_wait`, `agent_act`, `agent_detach`, отдельное чтение конфига. Точечные
  серверные интеграционные тесты. Коммит `feat(server): connect live agents to lobbies`.
- [x] **4. Сайт.** `GamesPage`, `LobbyPage`, `MatchStage`, API, стили. Сначала тест оповещения и управляющих
  элементов во время паузы. Показать роли в справке, статус ИИ, комментарии, действия паузы и восстановления,
  спойлер конфига. Коммит `feat(web): show AI participation and recovery controls`.
- [x] **5. Знания.** Обновить карточки SDK, игр, сервера, MCP и сайта. Добавить способ проверить
  наблюдение, ведение и восстановление через настоящий MCP и WebSocket.

## Живые проверки

- Пройти первый сценарий из активной сессии Codex с настоящим MCP Asobiba и игроками по WebSocket.
- Проверить браузер под хозяином и игроком, паузу, уведомление, спойлер, варианты восстановления
  и роли всех пяти игр. Сохранить результаты в `verify.md`.
- Выполнить `npm test`, `npm run build`, `npx tsc --noEmit` в этом порядке. После независимого
  ревью закрыть существенные замечания, провести PR и влить в `main` в автономном режиме.
