# 06. Quizor

**Quizor** — новая игра-конструктор квизов. Создатель с помощью своего агента собирает
квиз какой хочет: вопросы из цепочки блоков (текст, картинка, звук, видео), разные формы
ответа (текст, число, выбор, соответствие и другие), проверка алгоритмом или ведущим,
настраиваемые очки, штрафы и градации. Ход партии тоже настраивается: вопросы подряд,
табло с темами и стоимостями, их сочетание, особые вопросы и разные финалы. Главное
требование — гибкие настройки на уровнях квиза, раунда, вопроса и поля: всё названное
в брифе — только умолчания (P00 в [product.md](product.md)).

**Автономный режим:** разрешён владельцем 2026-11-12 до merge и push в main.
Идёт реализация по [plan.md](plan.md), затем QG и независимое ревью.
