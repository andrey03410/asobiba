# 02. Захват территории кубиками

Новая пошаговая игра для нескольких игроков на клетчатой карте. Каждый ход игрок бросает
два кубика и пристраивает к своей территории прямоугольник с такими сторонами, а замкнутое
кольцо из своих клеток забирает всё, что внутри. Первая итерация — ядро правил и редактор
карты: размер, стены, стартовые позиции.
