# Технические решения Yomifuda

Приняты агентом 17 ноября 2026 в разрешённом автономном режиме.
Свежий builder-check продукта: существенных вопросов нет.

## Исходная система

Проверены код и карточки SDK, games, server, web, MCP, video и dev-env.
`GameDefinition` уже поддерживает персональные view, presentRules, nextWakeAt/wake,
чистый RNG и отдельный клиент; Match записывает действия и восстанавливается по журналу.
ConfigService хранит оригинал JSON и сейчас отдаёт его владельцу через get/list/save.
LobbyService использует presentRules для DTO, но для старта берёт оригинал из БД.
NewLobbyPage имеет особый read-only сценарий Quizor и общий JSON-редактор остальных игр.
`@asobiba/video` уже подключает `@douga/video`, `@douga/render`, `@douga/player`.
В локальном коде douga проверены createVideoDocument, compileVideo, VideoNode с timing,
animation и motion, InteractivePlayer с startedAt/now/holdFrame. Пакеты уже установлены.
Дизайн рендерится тем же StudioVideo, что снимки; для встроенного шаблона не нужен импорт.

## Решения

### T01. Пакет и схема

- Варианты: отдельный пакет / расширение Quizor.
- Рекомендация и решение: `games/yomifuda`, id `yomifuda`, version 1, schema strict Zod.
  Все правила — JSON. `players` 2–6, `handSize` 1–20; attributes 1–32, cards 2–600.
  `deckSize` равен cards.length и кратен players, handSize <= deckSize/players.
  Характеристики — `{id,label,description?}`, карта — `{id,name,anime,version?,image?:{asset},shikimoriId?,values:Record<attributeId,number>}`.
  Целые значения в настраиваемой scale `{min:0,max:100}`. Полный набор значений обязателен.
  Умолчания: players3, handSize5, revealSeconds10, choiceSeconds0, winPoints1, tiePoints0.5,
  attributeMode `no-repeat` (также independent и bag). pool с профилями тройки и minViewers2.
  Рекомендованы 60 карт, до6 характеристик; возможность >6 не запрещаем.

### T02. Состояние и вид

- Варианты: один вид / закрытое состояние и whitelist view.
- Рекомендация и решение: закрытые карты, drawPile, hands, chosen живут только в state.
  Фазы `choose → reveal → review → choose|finished`. Один SDK-раунд = вся колода.
  Бой `round` начинается с1. Action `{type:'play',round,cardId}` или `{type:'ready',round}`.
  Номер боя обязателен, повторный ход и чужая карта отклоняются без мутаций.
  Последний play фиксирует исход и revealStartedAt, revealEndsAt. wake переводит в review;
  ready до срока недопустим. Все ready → добор и следующий показатель либо finished.
  Таймер выбора только отображается, timeoutPolicy skip и turnBudgetSeconds0 исключают автоход.
  view: phase, round, totalRounds, attribute, hand (только своя, без values), players
  `{seat,score,handCount,played,ready}`, table (рубашки либо разрешённые раскрытые карты
  с value/points/winner и tieTotal только у участников тай-брейка), stockCount,
  revealStartedAt/revealEndsAt, canPlay/canReady. В финале разрешён finalDeck с values.
  Итог по активному значению, затем сумме только разделивших максимум, затем tiePoints каждому.
  Банк карт и rawstate никогда не попадают в обычный вид или историю до финала.

### T03. Безопасный авторинг

- Варианты: вернуть секреты владельцу по умолчанию / отдельный явный доступ.
- Рекомендация и решение: ConfigDto Yomifuda по умолчанию с presentRules и
  `secretsHidden:true`; cards пусты, deckSize и публичные правила остаются.
  Оригинал доступен только внутреннему getOriginal и явному авторскому revealSecrets
  в config_get и HTTP GET своего конфига. Все проверки прав сохраняются.
  MCP validate по значению возвращает безопасную проекцию, по id — summary как сейчас.
  Save/list/get по умолчанию не выдают оценки. Lobby create by id и MCP операции by id
  используют оригинал внутри сервиса. На сайте Yomifuda — сводка и создание по configId,
  без JSON-редактора скрытой колоды; демонстрационный пресет можно запустить отдельно.

### T04. Визуал douga

- Варианты: встроенный шаблон / обязательный импорт снимка / новый CSS-рендерер.
- Рекомендация и решение: встроенный шаблон на createVideoDocument/compileVideo и
  InteractivePlayer douga. Он собирается только из разрешённого YomifudaView и отображаемых
  имён, никогда из полной колоды. Родной рендерер douga рисует фон, карты, подписи,
  раскрытие и анимацию чисел; React рисует личную руку, HUD, кнопки и доступный текст.
  Композиция square/vertical для телефона и wide для ПК, размеры/тема конфига влияют на шаблон.
  Во время choose видны только рубашки поставленных карт; reveal получает персонажей
  и текущие значения после всех ходов. Анимация синхронна по серверным временам.
  Ошибка рендера видна пользователю и имеет повтор, состояние и действия не теряются.
  Превью сервера — SVG из безопасной демонстрационной сцены, не симуляция реальной колоды.

### T05. Демо, руководство и изображения

- Варианты: обязательная внешняя генерация / небольшой учебный пресет.
- Рекомендация и решение: учебный пресет отдельно обозначен, не выдаётся за персональный
  пул 2из3. Реальные колоды агент формирует по guide с честной методикой и профилями.
  Оценки учебного пресета неизбежно доступны в capabilities, это не секретная колода пользователя.
  Портреты — необязательные ссылки на пул; отсутствие картинки имеет красивую нейтральную
  замену, не кодирует силу. Проверка вживую обязательно с импортированными портретами.
  Медиа ACL читает только свою руку/открытый стол и финальный разбор; чужая скрытая карта
  не разрешает её приватную картинку по одному известному id. Владелец своего пула сохраняет доступ.

### T06. Проверки

- Варианты: только правила / правила + реальная поверхность.
- Рекомендация и решение: TDD для правил, персональных проекций, ошибок действий,
  восстановления, тай-брейков и секретов HTTP/MCP. Реальная проверка настоящими MCP/WS,
  сценарии с тремя игроками и наблюдателем, запрет раннего ready, полное доигрывание,
  портреты, screenshot телефона 360×640 и390×844, ПК, fullscreen и кадры анимации douga.
  Обязательная тройка после последних правок, затем свежее ревью всей ветки.

## Затронутые зоны

- SDK/API — безопасный DTO и описание игры, без исполнения кода конфига.
- Games — новый пакет и каталог.
- Server/MCP — безопасные конфиги, оригинал для запуска, media ACL, превью.
- Web — клиент, сводка создания, полноэкранная сцена.
- Video — встроенный шаблон через существующие пакеты douga.
- Dev-env — новый воспроизводимый живой проверочный драйвер.
