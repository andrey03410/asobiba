## Границы вывода

Случайный smoke и победитель одной партии **не доказывают стратегический баланс**.
Диагностика говорит о заявленных геометрических метриках.
В этой части не проверялись браузерные FPS/жесты/ориентации/физический телефон;
это отдельная приёмка root. Финальная тройка остаётся root после последних правок.
Протокольная часть двух браузерных партий до результата закрыта после отдельного
разрешения; браузерные ограничения ниже остаются отдельными честными оговорками.

Переданные root наблюдения, которые исполнитель протокола сам не выполнял:
обычная партия получила один реальный SVG-click ход 5×1 при x30/y32;
turn0→turn1/verify-b, камера и hidden score сохранились. Manual drag менял камеру
без хода. В max root после смены ориентации подтвердил призрак 49×70 при x510/y651
настоящей кнопкой «Поставить»; следующая очередь перешла verify-b.
IAB отверг native fullscreen, пригодный full-window fallback сохранился
без неработающей кнопки. Native fullscreen не подтверждён. У IAB нет capability
`Input.dispatchTouchEvent`; физический телефон и настоящий pinch не проверены,
layout emulation / обычный pointer / математика жестов проверяются отдельно.
Код игры под ограничения этого инструмента исполнитель не менял.
