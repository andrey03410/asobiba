**Граница проверки:** IAB не предоставляет native touch dispatch, физического
телефона в доступной поверхности нет. Native Fullscreen API IAB отклонил;
проверен пригодный full-window fallback, без пустого экрана и неработающей кнопки.

pinch/tap остаются непроверенными. Мобильные размеры — viewport-эмуляция по T08.

## Что посмотреть руками

- Главная → Jinchi → Обычная / На троих / Гонка за флагами / Без сюрпризов.
- `/new?game=jinchi&preset=ordinary`: генератор R50/3, независимые кубики6/20,
  флаги и их цена/цель, пул неизвестного и вероятности; авторское вступление.
- В партии: скрыть счёт, раскрыть таблицу, портрет/альбомное окно, миникарта,
  zoom/drag, выбор/постановка, переброс; «Об игре» и итоговое разложение.
- У всех4 игр: «Об этой партии» / «Об игре», у Pole/Quizor не должны быть видны ответы.
- Повтор живого прогона: подготовить accounts по `verify`; `--independent` и `--stress`
  создают disposable протокольные сценарии. `--prepare`/`--prepare-info` готовят
  браузерные лобби; `--play-browser` продолжает их до итога **после** проверки UI,
  `--restore-check` только наблюдает. Драйвер читает секреты из storage, не печатает.

Замечаний владельца после реализации пока нет. Автономное решение: принять результат
на доступной и описанной поверхности T08; оговорённые hardware/fullscreen/LLM проверки
не выдаются за выполненные. Равные стратегические шансы случайным smoke не доказаны.
