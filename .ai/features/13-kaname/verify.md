# Приёмка

Результаты интеграционной проверки, сборки, типизации, браузерного входа и работающего релиза вносятся по мере выполнения.

## Независимое ревью и локальная проверка

Проверены изменения относительно origin/main, включая новый SDK, миграции, обработчики MCP и живого игрового соединения. Исправлены идентификация пользователя по паре issuer/subject, разделение старых и федеративных сессий/токенов, фильтрация панели и отчётов по issuer. Общий клиент проверяет подпись ID token, PKCE, nonce и state. Загрузка актива и публикация снимка Douga проверяют общую квоту также внутри завершающей SQLite-транзакции. Браузер использует текущую настройку гостевого доступа. Запросы защищённых файлов в централизованном режиме возвращают Cache-Control: private, no-store.

В Node 22.23.2 последовательно выполнены npm test (679 из 679, 70 файлов), npm run build и npx tsc --noEmit. Vite собрал приложение с предупреждением о размере основного JS-чанка. Интеграционная проверка запустила Asobiba на настоящем HTTP-порту с отдельной тестовой БД и локальной службой назначений. Подписанный на лобби WebSocket после отзыва закрылся с кодом 4401 до следующей отправки состояния лобби. Проверены отмена доступа у MCP-токена и сессии, изоляция одинакового subject другого issuer, байтовая квота и конкурентное создание конфигов. Проверочные данные принадлежат локальному тестовому окружению.

Сквозной вход с промышленным Keycloak, живую приёмку браузера, SHA и запуск на VPS координирует владелец общей выкладки.
