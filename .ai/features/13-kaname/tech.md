# Техника

OIDC authorization code, PKCE, nonce и state. Идентификатор проверенного аккаунта относится к настроенному issuer. Служебные ключи с разными направлениями, отдельные для каждой площадки. При ошибке проверки запись не разрешается. Данные продукта остаются в локальной БД. Свойства владельца не назначаются через пользовательские запросы.
