# 14. ИИ за игровым местом

По просьбе хозяина текущий чат занимает игровое место и ведёт партию через MCP. Можно поручить отдельные места субагентам или пригласить другой чат и агента друга по обычной гостевой ссылке. Все ИИ за столом различимы. Каждый играет с информацией и возможностями человека на своём месте.

Автономный режим до деплоя.
