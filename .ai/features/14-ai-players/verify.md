# Проверка ИИ-игроков

## Живая партия через MCP

В локальном процессе Asobiba с отдельной SQLite и разрешёнными гостями отработал `node scripts/verify-ai-players.mjs`. Независимые клиенты использовали обычную ссылку и получали события только своего места. В каждом сценарии сервер сообщил итог всем участникам. Полный отчёт: `storage/verification/14-ai-players/matches.json`.

| Игра | Что проверено |
| --- | --- |
| Крестики-нолики | Два одноимённых ИИ поставили фигуры со своих мест. |
| Jinchi | Два ИИ дождались бросков и разместили прямоугольники. |
| Русское поле | Игрок по вопросу сам ввёл догадку открытым текстом. |
| Quizor | Два участника подготовились к ответу и отправили собственный ответ. |
| Ёмифуда | Две руки, выбор карт, раскрытие, готовность и итог партии. |

Текущий чат через отдельный токен игрока создал стол на четверых по безопасному пресету и занял зарезервированное место. Два независимых гостя и подключённый по WebSocket хозяин заполнили остальные места. Чат выбрал центр и заблокировал линию соперника. Итог — ничья. Доказательство без ключей: `storage/verification/14-ai-players/current-chat.json`.

## Сайт и существующие роли

В Chromium проверены создание адресного приглашения, запрет старта до подключения, погашение ссылки независимым клиентом, видимость имени, максимального уровня и статуса, старт и подпись хода ИИ на игровом экране. Справка игры содержит роль игрока. Сценарий выполнился без ошибок страницы. Доказательства: `storage/verification/14-ai-players/browser.json`, `lobby.png`, `match.png`.

`node scripts/verify-game.mjs` завершил обычную WebSocket-партию победой первого места без ошибок клиентов. `node scripts/verify-mcp.mjs` прошёл путь организатора с ресурсом SVG, проверкой конфига, симуляцией 100 раундов, двумя PNG-превью, сохранением конфига и созданием лобби.

## Что посмотреть руками

- В настройках MCP выбрать токен «ИИ-игрок». В чистом чате попросить создать крестики-нолики на четверых и занять одно место.
- Скопировать ссылку лобби во второй игровой чат. При выключенном гостевом входе использовать собственный токен игрока. В составе проверить номера двух одноимённых ИИ.
- Для закрытого квиза дать адресное приглашение чату, который не видел вопросов. После старта дождаться собственного хода и сравнить раскрытие с экраном игрока.
