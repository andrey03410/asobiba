# План

**Цель:** заменить прототип на TypeScript-монорепо с агентским SDK, крестиками-ноликами
с гибкими правилами и визуалом, сервером с комнатами и MCP, сайтом.

**Подход:** снизу вверх. Сначала окружение и SDK с тестами, затем игра и рендерер,
затем сервер (вход, картинки, конфиги, лобби, комнаты, MCP), затем сайт. Каждый слой
покрыт тестами до следующего. В конце драйверы живой проверки и карточки знаний.

## Задачи

- [ ] **1. Монорепо и окружение.** Файлы: корневой `package.json` (workspaces, скрипты),
  `tsconfig.json`, `vitest.config.ts`, `.env.example`, `scripts/prisma.mjs`,
  `scripts/test-setup.ts`, `README.md`; удаление `backend/` и `frontend/`.
  Тесты: пустой прогон Vitest. Готово, когда: `npm install` ставит всё, `npm test` и `npx tsc --noEmit` проходят.
- [ ] **2. SDK: детали схемы, генератор, проверка конфига.** Файлы: `packages/sdk/src/{schema,rng,config,game,issues}.ts`.
  Тесты: детерминизм генератора, умолчания и ошибки с путями, версии, `checkRules`, сбор ссылок на картинки.
  Готово, когда: невалидный конфиг даёт понятные `issues`, валидный — нормализованный документ.
- [ ] **3. SDK: движок партии.** Файлы: `packages/sdk/src/match.ts`. Тесты на тестовых играх:
  ход не в свою очередь, серия и пауза, политика первого хода, таймер `skip`/`random`/`lose`,
  шаг реального времени, восстановление по журналу даёт то же состояние.
  Готово, когда: пошаговая и реалтайм тестовые игры доигрываются движком.
- [ ] **4. SDK: возможности и прогоны.** Файлы: `packages/sdk/src/{capabilities,simulate}.ts`.
  Тесты: JSON Schema содержит описания, прогон находит `never-ends`. Готово, когда: агенту есть что читать.
- [ ] **5. Крестики-нолики: правила.** Файлы: `games/tic-tac-toe/src/{rules,game,presets,visual}.ts`.
  Тесты: линии по направлениям, гравитация, мизер, «больше линий», 3–4 игрока, ходов за ход,
  заблокированные клетки, ничья без ходов, все пресеты проходят проверку и прогон.
- [ ] **6. Крестики-нолики: рендерер.** Файлы: `games/tic-tac-toe/src/client/*`. Тесты: статическая
  разметка содержит клетки, фигуры, слоты-картинки и линию победы. Готово, когда: тот же компонент
  рисует и сайт, и превью.
- [ ] **7. Сервер: база, вход, приглашения, токены.** Файлы: `apps/server/prisma/schema.prisma`, миграция,
  `apps/server/src/{app,env,db,main}.ts`, `apps/server/src/auth/*`, `scripts/invite.ts`.
  Тесты: регистрация только по приглашению, логин, сессия, админ, токены и отзыв.
- [ ] **8. Сервер: картинки и превью.** Файлы: `apps/server/src/assets/*`, `apps/server/src/preview/*`.
  Тесты: сигнатуры и лимиты, SVG → PNG, отказ SVG со ссылкой наружу, импорт по ссылке
  и отказ приватного адреса, одноразовая загрузка, превью PNG нужного размера.
- [ ] **9. Сервер: конфиги, лобби, комнаты, WebSocket.** Файлы: `apps/server/src/{configs,lobbies,games}/*`.
  Тесты: чужая картинка в конфиге отклоняется, лобби с замороженным конфигом, вход и старт,
  партия двух игроков по настоящему WebSocket до победы, таймер, восстановление после перезапуска.
- [ ] **10. MCP.** Файлы: `apps/server/src/mcp/*`. Тесты: настоящий HTTP-клиент MCP — токен,
  список инструментов, инструкция, сценарий агента от возможностей до лобби, картинка превью,
  отказы для чужих ресурсов.
- [ ] **11. Сайт.** Файлы: `apps/web/*`. Вход и регистрация, список лобби и создание (пресет,
  свой конфиг, форма по схеме, JSON), страница лобби с игрой, кабинет (токены с командой
  подключения, картинки, конфиги, приглашения). Готово, когда: `npm run build` собирает сайт.
- [ ] **12. Драйверы живой проверки.** Файлы: `scripts/seed-verify.ts`, `scripts/verify-mcp.mjs`,
  `scripts/verify-game.mjs`, `.claude/launch.json`, `.mcp.json`.
- [ ] **13. Знания.** Карточки `.ai/map/` всех зон, `AGENTS.md`, `CLAUDE.md`, скилл `verify`, `README.md`.

## Живые проверки

- `npm run dev` поднимает сервер и сайт; регистрация по приглашению в браузере.
- `scripts/verify-mcp.mjs`: агент по токену читает возможности, рисует фигуру в SVG,
  собирает конфиг, проверяет, прогоняет, получает PNG-превью, сохраняет и создаёт лобби.
- Партия двух игроков в браузере (две сессии): ходы видны обоим, линия победы, итог серии.
- `scripts/verify-game.mjs`: партия по WebSocket до победы.
- `npm start` после `npm run build`: сайт отдаётся с :8787.
