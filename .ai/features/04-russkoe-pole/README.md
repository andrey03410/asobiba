# 04. Русское поле

**Русское поле** — новая игра для 1–5 игроков: барабан с настраиваемыми секторами
(от обычных очков до русской рулетки и математики), табло с анимацией открытия букв,
произвольное число раундов и суперигра-кроссворд: соло или «Схватка» лучших. Основа — старый
прототип владельца `Pole.py` и правила телеигры о словах и барабане. Главное —
большая свобода настройки через SDK и базовые пресеты.

## Хвосты

- Полноэкранный режим сцены не проверен во встроенном браузере Claude: там `requestFullscreen`
  ждёт разрешения хоста. Проверить руками в обычном браузере.
- После перезапуска сервера доигранная партия не восстанавливается: лобби в `finished`
  открывается обычной страницей без доски. Так было и до задачи.
- У Jinchi на сцене две кнопки полного экрана: в панели сцены и в панели камеры. Обе делают одно.
