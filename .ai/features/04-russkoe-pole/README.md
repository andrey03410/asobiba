# 04. Русское поле

**Русское поле** — новая игра для 1–5 игроков: барабан с настраиваемыми секторами
(от обычных очков до русской рулетки и математики), табло с анимацией открытия букв,
произвольное число раундов и суперигра-кроссворд: соло или «Схватка» лучших. Основа — старый
прототип владельца `Pole.py` и правила телеигры о словах и барабане. Главное —
большая свобода настройки через SDK и базовые пресеты.
