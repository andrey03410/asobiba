# План

**Цель:** в каталоге есть «Русское поле»: партия 1–5 игроков по сети, барабан из секторов
SDK, табло, суперигра соло и «Схватка», шесть пресетов. Ответ не виден ни в `view`,
ни в конфиге лобби, ни в бандле сайта.

**Подход:** сначала часы фазы в SDK и выдача лобби без секретов, затем чистый движок
с тестами на скрипт партии, потом доска и регистрация. Случайный прогон — дымовой:
партия заканчивается и не отдаёт ответ.

## Задачи

- [ ] **1. Часы фазы.** Файлы: `packages/sdk/src/game.ts`, `packages/sdk/src/match.ts`, тест движка. Готово, когда: игра с `turnBudgetSeconds` получает свой дедлайн, игра без метода — прежний `timer.turnSeconds`, таймаут по-прежнему зовёт `passTurn`.
- [ ] **2. Конфиг лобби без ответов.** Файлы: `GameDefinition.presentRules`, `apps/server/src/lobbies/service.ts`, тест лобби. Готово, когда: у игры с методом в `LobbyDto.config` нет исходных ответов, у крестиков конфиг не меняется, партия на сервере идёт по полному документу.
- [ ] **3. Схема, алфавит, кроссворд, банк.** Файлы: `games/russkoe-pole/src/rules.ts`, `alphabet.ts`, `crossword.ts`, `bank.ts`, `bank-slot.ts`. Тесты раскладки и проверки конфига. Готово, когда: слово вне алфавита и кроссворд без пересечения — ошибки с подсказкой, банк не импортируется из `index.ts`.
- [ ] **4. Движок партии.** Файлы: `game.ts`, `presets.ts`, `guide.ts`, `visual.ts`, `present.ts`. Тесты: очки, банкрот, промах, слово целиком, жизни, рулетка, математика, кража, шкатулки, соло-суперигра, «Схватка» (тайные буквы, пакость, первый верный забирает слово), потолок вращений, `view` без ответа, все пресеты валидны, `simulate` не даёт `stuck` / `never-ends` / `illegal-legal-action`. Готово, когда эти партии зелёные.
- [ ] **5. Доска.** Файлы: `client/Board.tsx`, `css.ts`, `index.ts`, тест разметки. Готово, когда: живая доска — HTML с кнопкой «Крутить», плитками и панелью очков; `staticRender` — один SVG без текста ответа; названные буквы и мини-окошко зависят от состояния.
- [ ] **6. Каталог.** Файлы: `package.json` игры, зависимости сервера и сайта, оба каталога, короткий текст правил на странице лобби. Сервер вызывает `useWordBank`. Готово, когда: игра есть в `/api/games` и в форме нового лобби.
- [ ] **7. Знания.** Карточки `.ai/map/sdk.md`, `games.md`, `server.md`, `web.md`, `mcp.md` совпадают с кодом.

## Живые проверки

- Тройка: `npm test`, `npm run build`, `npx tsc --noEmit`.
- MCP: возможности `russkoe-pole`, `config_validate`, `config_simulate`, `config_preview` (PNG), лобби. В тексте превью и в `view` нет ответа.
- WebSocket: два игрока доигрывают короткую партию со своими словами.
- Браузер: пресет, барабан, ход, табло. В панели конфига лобби ответа нет.
- Бандл сайта не содержит уникальную строку из серверного банка.
