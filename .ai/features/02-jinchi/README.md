# 02. Jinchi

**Jinchi** (陣地, «занятая позиция, территория») — новая пошаговая игра для нескольких
игроков на клетчатой карте. Каждый ход игрок бросает два кубика и пристраивает к своей
территории прямоугольник с такими сторонами, а замкнутое кольцо забирает всё, что внутри.
Первая итерация — ядро правил, редактор карты (размер, стены, стартовые позиции),
полноэкранный режим и удобная навигация по большой карте.

**Автономный режим:** разрешён владельцем 2026-11-05, до вливания в main.
Продуктовые решения P01–P20 приняты агентом в рамках этого поручения.
