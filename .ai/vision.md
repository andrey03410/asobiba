# Видение Asobiba

Живой документ: что строим и по каким принципам. Меняется, когда меняется
продуктовое видение владельца. Решения конкретных задач лежат в `features/`.

## Что это

**Asobiba** (遊び場, «игровая площадка») — сайт мини-игр для владельца и его друзей.
Новые игры добавляет разработчик. Любой игрок настраивает существующие игры под себя
через очень гибкие настройки: правила, режимы, раунды, таймеры, визуал поля и фигур.

Главный сценарий — через агента. Человек пишет своему ИИ-агенту, какую игру хочет
(конкретно или размыто: «придумай свои фигуры», «сделай смешной визуал»). Агент через
MCP узнаёт возможности игры, собирает из них конфиг, проверяет его, смотрит превью
и создаёт лобби. Друзья заходят по ссылке и играют.

## Принципы

1. **Человек — данные, SDK — возможности агента.** Конфиг игры — это данные
   (JSON по версионированной схеме). Агент и человек выбирают только из того, что
   описал разработчик. Новая возможность — это расширение схемы, движка и рендерера,
   а не код в конфиге. Произвольный JS из конфига не исполняется никогда.
2. **Мелкие детали вместо готовых вариантов.** Чем мельче детали, тем больше агент
   может придумать сам. Готовые варианты — это пресеты поверх деталей.
3. **Одна схема — один источник.** Схема настроек на Zod даёт проверку, типы,
   форму на сайте и JSON Schema для MCP.
4. **Детерминированная логика.** Игра — чистые функции над обычным JSON и генератор
   случайных чисел с зерном. Партию можно повторить по конфигу, зерну и списку
   действий. Сервер — единственный судья.
5. **Логика отдельно от отрисовки.** Логика не знает, как её рисуют. Сейчас 2D
   (SVG, Canvas), 3D позже станет ещё одним рендерером.
6. **Агент не играет за людей.** Он собирает игры и лобби, ходы делают люди.
7. **Маленькая нагрузка.** Сайт для своих: один процесс, SQLite, без масштабирования.

## Виды игр

| Вид | Примеры | Как работает |
|---|---|---|
| Пошаговые | крестики-нолики, шахматы | ход → сервер проверяет → новое состояние |
| Событийные | квиз, крокодил | события и серверные таймеры, каждый видит только своё |
| Непрерывные | гонки, простые стратегии | фиксированный шаг симуляции на сервере, плавная отрисовка в браузере |

## Дальние цели

- Игры реального времени: квизы, крокодил, гонки, стратегии.
- Ролики по повторам партий через Douga. Интерактивные видео-игры на движке Douga уже есть:
  картинку рисует douga, правила и партия остаются в asobiba ([video](map/video.md)).
- 3D — очень дальняя перспектива и не блокер.
